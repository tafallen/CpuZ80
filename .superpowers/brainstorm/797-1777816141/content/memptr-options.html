MEMPTR (WZ Register): The Final Frontier of Accuracy

Achieving bit-perfect flag behavior for undocumented opcodes

The Problem: Approximate Flags
// Current implementation (Cpu.Arithmetic.cs)
F = (byte)((F & ~0x28) | (result & 0x28));
Issue: While 90% correct, this fails strict ZEXALL tests for block ops and bit manipulation.
The Solution: Hidden 16-bit WZ Register
// Correct implementation using MEMPTR
F = (byte)((F & ~0x28) | ((MEMPTR >> 8) & 0x28));
Benefit: CRC-perfect functional accuracy. Identical to original Silicon.

Implementation Approaches

1

Explicit WZ Register

Add ushort WZ to the core registers. Update it manually in every instruction that touches it (most memory/jump instructions).

2

Generator-Managed MEMPTR

The Code Generator automatically injects MEMPTR updates based on opcode type. Reduces manual error in tracking this tricky register.

3

Lazy Evaluation

Only track MEMPTR for instructions where it affects the visible Z80 state (Block ops, BIT). Fast, but technically less accurate internally.
